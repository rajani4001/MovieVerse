# MovieVerse

A full-stack MERN Movie Discovery Platform that enables users to explore trending, popular, top-rated, and upcoming movies with secure authentication, personalized watch history, favorites, and an admin dashboard.

---

## Live Demo

Frontend: https://movie-verse-blush.vercel.app

Backend API: https://movieverse-qwuc.onrender.com

---

# Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/MovieVerse.git
```

---

## Backend

```bash
cd backend

npm install

npm run dev
```

---

## Frontend

```bash
cd frontend

npm install

npm run dev
```

---

# Environment Variables

Create a `.env` file inside the **backend** folder.

```env
PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_jwt_secret

TMDB_API_KEY=your_tmdb_api_key

NODE_ENV=development

FRONTEND_URL=http://localhost:5173
```
